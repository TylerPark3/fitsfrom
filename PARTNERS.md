## The pitch (when traffic exists)

Subject: "Your pieces, identified — [X] clicks last month"
1. Show them the fit file already featuring them (traffic receipts).
2. Ask: exclusive code (`FITSFROM15`) + 15% direct commission — self-proving attribution, no network cut.
3. Sweetener: their brand gets a "worn by" chip and a permanent file page that ranks in search.

*Rule: feature first, monetize second. The archive is the leverage.*
